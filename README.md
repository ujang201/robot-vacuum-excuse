# Robot Vacuum's Best Excuse

A robot vacuum explains, in one line, why it missed a spot — in its own words.

> I mapped that spot, circled it twice, then my battery filed a formal complaint and my dock offered me a better life. I took it.

The joke lives in the vacuum's world: its map, its battery, its dock. It did the laps, the battery went on strike, and the dock made a better offer. Any tired homeowner who has watched a little disc give up halfway across the living room knows exactly how this ends.

The line is 127 characters — inside the 140-character cap — and the program refuses to write anything longer, so the gate can never see an invalid entry from this code.

## Run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). Requires Node 22.18+.
